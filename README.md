# Invitación Digital

Invitación digital premium desarrollada para la boda de Juan Diego & Valeria.

## Tecnologías

**Frontend:** React, TypeScript, Tailwind CSS, Vite, React Router.
**Backend:** Express, Prisma, PostgreSQL (Neon), desplegado como Serverless
Functions en el mismo proyecto de Vercel — ver [`server/README.md`](./server/README.md).

## Objetivo

Crear una experiencia digital inspirada en Apple y el diseño editorial, con RSVP
real y un panel administrativo para los novios.
