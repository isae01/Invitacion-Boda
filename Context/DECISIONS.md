# Decisiones

## Diseño

- Inspiración Apple.
- Mucho espacio en blanco.
- Editorial.
- Steel Blue.

---

## Desarrollo

- React Router.
- Tailwind v4.
- Firebase Firestore.
- Sin API de Google Maps.

---

## Animaciones

- Scroll driven.
- Intersection Observer.
- requestAnimationFrame.

---

## Fotos

Todas deben utilizarse.

No repetir fotografías.

Excepto cuando sea intencional.

---

## Itinerario

Sin iconos.

Sin emojis.

Línea vertical.

Puntos minimalistas.

---

## Filosofía

Siempre preferir una solución sencilla sobre una arquitectura compleja.

El proyecto tiene fines educativos.

Toda decisión debe favorecer que el código sea fácil de entender.
